# SWARAJ LABS / NETWORK

> A visual exploration of how computer networks work.

[🌐 Live Demo](https://swaraj-labs.vercel.app)

---

NETWORK is an interactive learning experience that visualizes
how data travels through a computer network.

Instead of treating communication as a direct connection between
two computers, NETWORK presents the journey of a packet through
multiple network nodes.

## Current

- Routed network simulation
- Sender → Router 01 → Router 02 → Gateway → Receiver
- Animated packet journey
- Packet Inspector
- Network hops and forwarding stages
- Message transmission
- Payload and packet information
- Interactive learning sections
- Transmission statistics

## Learning Experience

The simulation is designed to make the journey of data visible.

A message is introduced at the sender, represented as a packet,
and then visualized as it travels through the network toward the
receiver.

The Packet Inspector provides a closer look at what is travelling
through the network and helps connect the visual simulation with
the underlying networking concepts.
